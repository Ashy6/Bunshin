# ai-bunshin 产品需求文档

版本：v0.1

状态：方案确认稿
产品形态：开源、单站长、自托管

## 1. 产品定位

`ai-Bunshin` 是一个将个人简历、博客文章和长期知识积累组合成公开网站与 AI 个人分身的开源项目。

访客可以浏览全部公开信息，并与“个人分身 Agent”对话。站长通过独立后台维护个人资料、文章与 RAG 数据源，配置模型渠道，查看调用量、Token 和估算费用。

## 2. 产品目标

- 公开站点简洁、内容优先，支持移动端和深浅色模式。
- 文章、简历和知识库只维护一份事实源，避免内容漂移。
- AI 回答可追溯、有引用，资料不足时不编造。
- 任意开发者可以克隆仓库并部署到自己的 Cloudflare 账户。
- 不配置 AI 时，简历和博客仍能完整运行。

## 3. 角色

### 3.1 访客

访客无需注册，可以：

- 浏览首页、简历、经历、项目、文章、分类、标签和归档。
- 搜索公开文章。
- 与个人分身 Agent 进行流式对话。
- 查看回答引用的简历条目、项目、文章或知识条目。
- 下载站长公开的简历文件。

访客不能：

- 查看后台或未发布内容。
- 访问标记为“仅供 RAG”的原始文档。
- 修改知识库或查看模型配置。

### 3.2 站长

系统只有一个站长账号。站长可以：

- 管理个人资料、工作经历、项目、技能和联系方式。
- 创建、编辑、预览、发布和下线文章。
- 管理分类、标签、文章目录和归档。
- 输入文字或上传 PDF/Markdown/TXT 作为知识源。
- 选择已有分类、即时新建分类或保持未分类。
- 执行解析、切片、向量化、重建索引和检索测试。
- 配置任意模型厂商的 API Key、Base URL 和模型。
- 查看调用量、Token、费用估算、错误率和延迟图表。

## 4. 公开访客端

### 4.1 全局导航

导航项按内容是否存在动态显示：

- 首页
- 问问分身
- 文章
- 分类：至少存在一个已发布文章分类时显示。
- 标签：至少存在一个已使用标签时显示。
- 归档：至少存在一篇已发布文章时显示。
- 关于

### 4.2 首页

首页包含：

- 个人头像、名称、职业定位和简介。
- AI 提问入口。
- 置顶或最新文章列表。
- 最近更新。
- 热门标签。
- 社交链接与联系方式。

参考站点的侧边栏、文章卡片、分类/标签/归档和深浅色切换方式，但使用本项目独立的设计令牌与组件实现。

### 4.3 简历与关于

- 个人概要。
- 工作经历时间线。
- 代表项目。
- 技能与技术栈。
- 教育经历。
- 可选 PDF 简历下载。
- 每个模块为空时自动隐藏。

### 4.4 文章

文章字段：标题、Slug、摘要、正文、封面、分类、标签、状态、发布时间、更新时间、置顶、SEO 描述、是否进入 RAG。

文章能力：

- Markdown 渲染、代码高亮、表格、引用、图片和脚注。
- 根据标题层级自动生成目录。
- 阅读进度、上一篇/下一篇。
- 分类、标签、归档和全文搜索。
- 草稿、定时发布和已发布状态。
- 更新或下线时同步更新 RAG 索引。

### 4.5 个人分身 Agent

交互能力：

- 推荐问题。
- 流式输出、停止生成和重新生成。
- 会话内上下文，不提供跨访客长期记忆。
- Markdown 回答和引用卡片。
- 对问题长度、频率和每日次数限流。
- 站长可以关闭 Agent；关闭后入口自动隐藏。

回答约束：

- 只依据检索到的个人资料回答事实性问题。
- 区分“资料中的事实”和“模型推断”。
- 没有证据时明确说明资料中没有相关信息。
- 每个关键事实尽量关联来源。
- 不向访客返回后台私密字段、API Key 或未公开原文。

## 5. 后台管理端

### 5.1 登录与安全

- 单管理员邮箱/密码登录。
- 首次部署通过初始化命令创建管理员。
- 支持 TOTP MFA 和一次性恢复码。
- 登录失败限流、会话管理、修改密码和退出全部会话。
- 后台路由不得被搜索引擎索引。

### 5.2 仪表盘

使用 ECharts 展示：

- 请求量趋势折线图。
- 输入/输出/Embedding Token 堆叠图。
- 估算费用趋势图。
- 模型与渠道占比图。
- P50/P95 响应延迟。
- 成功率、错误率、限流次数。
- RAG 命中率、拒答率和热门问题。
- 文档数量、切片数量、索引任务状态。

筛选维度：今天、7 天、30 天、自定义时间、模型、渠道和调用场景。

### 5.3 模型渠道

预置 OpenAI、Anthropic、Gemini、DeepSeek、OpenRouter、Groq、通义、智谱、Moonshot、Ollama，并支持 OpenAI-compatible 自定义渠道。

配置项：

- 渠道名称、厂商类型、Base URL、API Key。
- Chat 模型、Embedding 模型、可选 Rerank 模型。
- 输入、输出、缓存与 Embedding 单价。
- 月度预算。
- 是否启用、是否默认。

能力：连接测试、模型测试、Key 更新、渠道禁用、Chat/Embedding 分渠道配置和失败降级。

“余额”必须区分：

- 厂商余额：仅厂商提供余额 API 时显示。
- 本地预算剩余：月度预算减去本地估算费用。

不得把预算估算展示为厂商真实余额。

### 5.4 知识库

支持数据源：

- 直接输入文字。
- Markdown/TXT 文件。
- PDF 文件；MVP 仅支持可复制文字的 PDF，扫描 PDF/OCR 后续实现。
- 已发布文章。
- 简历、工作经历和项目。

导入流程：

1. 选择数据源。
2. 选择已有分类、创建分类或保持未分类。
3. 设置可见性：公开来源、仅供 RAG、完全私有。
4. 上传并异步解析。
5. 预览解析结果并允许人工修正。
6. 切片、生成 Embedding、写入向量索引。
7. 显示成功、部分失败或失败状态。

文档操作：编辑、启停、重新解析、重建索引、移动分类、查看切片、测试召回和删除。

### 5.5 分类与标签

- 分类可用于文章、知识库或两者共用。
- 文章 MVP 只允许一个主分类，标签可多个。
- 删除分类不删除内容，内容变为未分类。
- 无已发布内容的分类不在前台展示。

### 5.6 用量记录

记录请求时间、场景、渠道、模型、输入/输出/缓存/Embedding Token、估算费用、耗时、状态码、错误类型和匿名访客标识。

调用场景包括：访客问答、Query 改写、Embedding、Rerank、文章摘要和后台测试。

## 6. MVP 范围

必须交付：

- 两个应用：公开 Web 与 Admin。
- 简历、项目和文章内容管理。
- 分类、标签、归档、文章目录与搜索。
- 文本、Markdown、TXT 和文本型 PDF 导入。
- 异步解析、切片、向量化和检索测试。
- OpenAI-compatible Chat/Embedding 渠道。
- 带引用的流式 RAG 对话。
- ECharts 用量与费用看板。
- 单管理员登录、TOTP MFA。
- Cloudflare 一键部署说明。

暂不实现：

- 访客注册、组织、多租户和 RBAC。
- 支付、充值和代售模型额度。
- OCR、音视频知识源。
- 评论系统和跨站社交功能。
- 自主执行外部操作的通用 Agent。

## 7. 验收标准

- 未配置模型时，公开简历和博客仍可访问，Agent 入口隐藏。
- 无分类时，前台不显示分类导航。
- PDF 上传后可选择或新建分类，并能查看处理状态和解析结果。
- 文章发布、更新、下线能正确同步 RAG 索引。
- AI 无有效证据时不生成肯定性经历或数据。
- 每次模型调用都有可查询的 Token、费用估算和状态记录。
- API Key 不出现在浏览器响应、日志或数据库明文字段中。
- 公开文章有独立可索引 URL、canonical、结构化数据和 Sitemap。
